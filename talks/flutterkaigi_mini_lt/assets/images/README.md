# 登壇固有の画像置き場

ここに置いた画像は `pubspec.yaml` の `assets:` 経由で読み込まれる。
共通で使い回すもの（登壇者アイコンなど）は `packages/slide_kit/assets/images/` 側に置く。

## 必要な画像

| ファイル名 | 用途 |
|---|---|
| `dashumaru.png` | プロポーザルのスライド。スピーカー特典のぬいぐるみ「だしゅまるくん」 |
| `overflow_title.png` | あるある①「見せる」。タイトルスライドをオーバーフローさせた**タイトル周りだけの切り出し** |
| `sticker_overflow.jpg` | あるある①「説明」。FlutterKaigi 2025 のステッカー（だしゅまる＆オーバーフロー柄）の写真 |
| `aruaru2_shot.png` | あるある②「見せる」。実際に出た「画像が出ない」エラーのスクショ |
| `aruaru3_shot.gif` | あるある③「見せる」。テキストが崩れる様子の gif |
| `aruaru3_ok.gif` | あるある③「説明」右。正常ケースの動画 gif |
| `aruaru4_shot.gif` | あるある④「見せる」。日本語入力が「？！おえういあ」になる gif |
| `aruaru4_ok.gif` | あるある④「説明」右。正常ケースの動画 gif |

未配置の画像はプレースホルダにフォールバックするので、揃っていなくてもデッキは動く。
画像を追加したあとは `flutter pub get` とホットリスタート（ホットリロードでは反映されない）。

## `overflow_title.png` の作り方（重要）

このデッキは `FlutterDeckSlideSize.responsive()` で動くため、flutter_deck は
画面サイズに応じた拡大縮小を**しない**。文字は常に固定 px で描画される。

そのため全画面のスクリーンショットを敷くと、画像だけが画面幅に比例して伸縮し、
登壇先のプロジェクタが手元の PC と解像度が違うと実物の文字サイズとズレる。

1. デッキを 1920x1080 で表示し、タイトルスライドをオーバーフローさせた状態にする
2. **タイトル周りだけ**を切り出す（全画面ではなく）
3. 高 DPI 環境で撮るとピクセル数が 2 倍になるので、その場合は
   `slides.dart` の `shotWidth` に論理 px（1920 基準の幅）を明示する

表示は `CenteredImageLayout` が伸縮させずに実寸で中央に置くので、
切り出し位置さえ合っていれば実物のタイトルスライドに重なって見える。
